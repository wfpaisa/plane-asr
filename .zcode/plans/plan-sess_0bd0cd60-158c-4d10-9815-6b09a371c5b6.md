# Plan: Grabación + Transcripción ASR para plane-asr

## Visión general

Sistema reutilizable y programable de ASR local que graba con `pw-record`/`parecord` (16 kHz mono s16) y transcribe con cualquier binario configurable mediante **presets** + modo **custom**. Salida al portapapeles o auto-pegado en el foco. Atajo de teclado global para toggle.

### Máquina de estados (`AsrService`)

```
IDLE  --[toggle]-->  RECORDING  --[toggle]-->  TRANSCRIBING  -->  IDLE
                                              --[cancel]------->  IDLE
```

El `Indicator` observa los estados y actualiza la UI. El `AsrService` es el único orquestador (el `Indicator` solo dispara `service.toggle()` / `service.cancel()`).

## 2. Archivos nuevos

### `src/extension/asr-backends.ts` — abstracción reutilizable

```ts
export interface AsrBackend {
    id: string;
    label: string;
    defaultCliName: string; // placeholder del Entry en prefs
    supportsRealtime: boolean;
    buildArgv(o: {
        cliPath;
        modelParams;
        realtime;
        customTemplate;
        audioPath;
    }): string[];
}
export const ASR_BACKENDS: AsrBackend[] = [
    /* whisper-cli, transcribe-cli, nero-asr, custom */
];
export function getBackend(id: string): AsrBackend;
export function parseArgs(s: string): string[]; // tokenizador shell (maneja "y")
```

- `whisper-cli`: `[cli, ...params, audio]` (sin realtime)
- `transcribe-cli`: `[cli, ...params, realtime?('--stream-chunk-ms','500'), audio]`
- `nero-asr`: `[cli, ...params, audio]`
- `custom`: reemplaza `{cli}`/`{params}`/`{audio}` en `customTemplate` y luego `parseArgs`
- `parseArgs` implementa el item #4 del plan (manejo de rutas con espacios) — split respetando `'`/`"`.

### `src/extension/recorder.ts` — grabación

```ts
export class Recorder {
    isRecording(): boolean;
    start(outputPath: string): void; // lanza pw-record/parecord 16k/mono/s16
    stop(): Promise<void>; // SIGINT (2) + wait_check_async
}
```

- Detección: `GLib.find_program_in_path('pw-record')` → `['pw-record','--rate','16000','--channels','1','--format','s16',out]`
- Sino `parecord --rate=16000 --channels=1 --format=s16le --file-format=wav out`
- Si ninguno → `throw new Error(_('No pw-record/parecord found'))`
- `stop()` envía `proc.send_signal(2)` y resuelve al cerrar el WAV limpio.

### `src/extension/transcriber.ts` — invocación del ASR

```ts
export class Transcriber {
    constructor(settings: Gio.Settings);
    transcribe(
        audioPath: string,
        onCancel?: (p: Gio.Subprocess) => void
    ): Promise<string>;
}
```

- Construye argv con `getBackend(...).buildArgv(...)`.
- `new Gio.Subprocess({argv, flags: STDOUT_PIPE})` → `communicate_utf8_async(null, null, cb)` → `communicate_utf8_finish(res)` retorna `[bool, stdout, stderr]`.
- Conserva referencia al proc para que `AsrService.cancel()` pueda `force_exit()`.

### `src/extension/asr-service.ts` — orquestador

```ts
export enum AsrState {
    IDLE,
    RECORDING,
    TRANSCRIBING,
}
export class AsrService {
    constructor(settings, onChange: (s: AsrState, ctx?) => void);
    get state(): AsrState;
    toggle(): Promise<void>; // IDLE→start, RECORDING→stop+transcribe, TRANSCRIBING→noop
    cancel(): void; // force_exit del transcribe proc si está activo
}
```

- `start()`: valida `Gio.File.new_for_path(cliPath).query_exists(null)` (item #3 del plan); crea `~/.cache/planeasr/recording_<unix_ms>.wav` con `GLib.mkdir_with_parents(dir, 0o755)` (corrección: NO `dir_make_with_parents`); guarda `last-audio-path`; lanza `Recorder.start()`.
- `stop()`: pasa a TRANSCRIBING → `await recorder.stop()` → `await transcriber.transcribe(path)` → guarda `last-text` → `_output(text)` → `Main.notify(_('Transcription complete'))`. Errores → `Main.notifyError` o notify con mensaje. Vuelve a IDLE.
- `_output()`: lee `output-mode`; `paste` → `pasteAtCursor(text)` de `util/paste.ts`; `clipboard` → `St.Clipboard.get_default().set_text(CLIPBOARD, text)`.

### `src/util/paste.ts` — auto-pegar con teclado virtual

Tu código pegado con las correcciones verificadas:

```ts
export function pasteAtCursor(text: string): void {
    const clipboard = St.Clipboard.get_default();
    clipboard.get_text(St.ClipboardType.CLIPBOARD, (cb, previousText) => {
        cb.set_text(St.ClipboardType.CLIPBOARD, text);
        const seat = Clutter.get_default_backend().get_default_seat();
        const kb = seat.create_virtual_device(
            Clutter.InputDeviceType.KEYBOARD_DEVICE
        );
        const tUs = Clutter.get_current_event_time() * 1000; // ms→µs (verificado)
        kb.notify_keyval(tUs, Clutter.KEY_Control_L, Clutter.KeyState.PRESSED);
        kb.notify_keyval(tUs, Clutter.KEY_v, Clutter.KeyState.PRESSED);
        kb.notify_keyval(tUs, Clutter.KEY_v, Clutter.KeyState.RELEASED);
        kb.notify_keyval(tUs, Clutter.KEY_Control_L, Clutter.KeyState.RELEASED);
        GLib.timeout_add(GLib.PRIORITY_DEFAULT, 300, () => {
            if (previousText)
                cb.set_text(St.ClipboardType.CLIPBOARD, previousText);
            return GLib.SOURCE_REMOVE;
        });
    });
}
```

Correcciones aplicadas: `create_virtual_device` (no `_input_`), `time_us` en µs (`* 1000`), `mkdir_with_parents` en otro módulo, check defensivo de `previousText`.

## 6. Consideraciones abiertas / decisiones tomadas

1. **Atajo por defecto `<Super>A`**: va habilitado al instalar (puede colisionar; el usuario puede dejarlo vacío en prefs).
2. **Cancelación**: click primario durante TRANSCRIBING llama `cancel()` → `force_exit()` del proc de transcripción; el WAV ya grabado se conserva en `last-audio-path`.
3. **`parseArgs` con comillas**: tokenizador simple que respeta `"…"` y `'…'` y backslash-escape. Mejora sobre el `.split(' ')` del plan original.
4. **`nero-asr` preset**: lo dejo con `argv = [cli, ...params, audio]`. Si la sintaxis difiere, es trivial añadir/quitar flags en su `buildArgv`.
5. **No se tocan** `animate`/`padding-inner` (scaffold existente) ni `metadata.json` (shell-version sigue siendo `["50"]`).
6. **`extension.ts`/`prefs.ts`** raíz siguen siendo shims de re-export (regla AGENTS.md).

Si aprobás, implemento en este orden: schemas+settings → `asr-backends.ts`/`recorder.ts`/`transcriber.ts`/`paste.ts` → `asr-service.ts` → `indicator.ts` + `index.ts` → `prefs/index.ts` → `stylesheet.css` → build+lint+format.
